A two-player TicTacToe that runs in your terminal on a 3x3 grid.

Requirements: python3

How to run: python3 main.py

How to play: The grid numbers are 1 - 9, 1 being the top left and 9 being the bottom right. It switches players automaticaly, so you just have to input the number of the grid you want and it will place the marker.

Features: Picking an invalid grid number or character will not result in a loss of that okayers turn. It will just print "Invalid Position" or "Invalid Character" and give you back your turn.

Project structure: The project contains four main code files, one for generating and printing the board, one for managing any endings of the game that may ocure, one for managing the players, so for getting the player input and switching the players, and one, main.py, for running all the functions and server as the file you run when wanting to play the game.
